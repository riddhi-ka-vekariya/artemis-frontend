# Artemis Frontend — 3D Chair Viewer

A 3D product showcase built with **React**, **Three.js**, **@react-three/fiber**, and **@react-three/drei**.

## Features
- 📦 GLB model auto-normalized to fit viewport (bounding box scaling)
- 🌍 Environment lighting presets (Studio, Sunset, City, Night)
- 📱 Gyroscope chair rotation on mobile devices
- 🎥 Smooth OrbitControls for desktop (drag, zoom, pan)
- 💡 Dynamic spotlight with accent color
- 🌑 Contact shadows on ground plane

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
